## 三、服务调用关系（时序泳道图）

### 3.1 脑肿瘤检测流程（detect 模式）

```mermaid
sequenceDiagram
    actor User as 用户
    participant Vue as Vue 前端 (:9527)
    participant SB as Spring Boot 后端 (:9090)
    participant DB as MySQL
    participant YOLO as YOLO detect-api (:5001)
    participant LLM as LLM (DeepSeek/GLM/Kimi)

    %% 上传阶段
    User->>Vue: 上传医学影像
    Vue->>SB: POST /detect/upload (file)
    SB->>SB: 保存文件到 uploads/
    SB->>DB: 创建检测记录 (status=0)
    DB-->>SB: record id
    SB-->>Vue: 返回记录ID + 图像URL
    Vue-->>User: 显示上传的图像

    %% 检测阶段
    User->>Vue: 选择模型，点击"开始检测"
    Vue->>SB: POST /detect/startDetect/{id}
    SB->>DB: 更新状态 (status=1 检测中)
    SB->>YOLO: POST /detect (file, pt_path, conf)
    YOLO->>YOLO: YOLO 模型推理
    YOLO-->>SB: 返回检测框 + 置信度 + 结果图base64
    SB->>SB: 保存结果图像到 uploads/
    SB->>DB: 更新检测记录 (status=2, detection_data)
    SB->>DB: 记录检测日志
    SB-->>Vue: 返回检测结果
    Vue-->>User: 显示检测框 + 结果图像

    %% AI分析阶段
    User->>Vue: 选择AI模型，点击"AI分析"
    Vue->>SB: POST /detect/aiAnalysis/{id}?model=deepseek
    SB->>DB: 更新AI状态 (status=1 分析中)
    SB->>LLM: 调用 Chat Completions API
    LLM-->>SB: 返回诊断建议文本
    SB->>DB: 保存分析结果 (status=2)
    SB-->>Vue: 返回分析报告
    Vue-->>User: 显示AI诊断报告
```

### 3.2 脑肿瘤分割流程（mask 模式）

```mermaid
sequenceDiagram
    actor User as 用户
    participant Vue as Vue 前端 (:9527)
    participant SB as Spring Boot 后端 (:9090)
    participant DB as MySQL

    User->>Vue: 上传医学影像，选择分割模式
    Vue->>SB: POST /detect/upload (file)

    SB->>DB: 更新记录 (status=2)

    %% AI分析 (同detect模式)
    User->>Vue: 点击"AI分析"

    SB-->>Vue: AI报告
    Vue-->>User: 显示诊断报告
```

### 3.3 批量分割流程

```mermaid
sequenceDiagram
    actor User as 用户
    participant Vue as Vue 前端 (:9527)
    participant SB as Spring Boot 后端 (:9090)
    participant DB as MySQL
    participant UNet as UNet unet4engine (:3408)
    participant FS as 文件系统

    User->>Vue: 选择输入文件夹，配置参数
    Vue->>SB: POST /segment/batch (folderPath, outputPath, model 参数)
    SB->>UNet: POST /segment/batch
    UNet-->>SB: 返回 jobId (异步任务)

    loop 每张切片
        UNet->>UNet: 加载图像 → resize → 模型推理
        UNet->>FS: 保存 slice_{n}.npy 到 images/
        UNet->>FS: 保存 mask_{n}.npy 到 masks/
        UNet->>SB: 轮询进度 (GET /segment/progress/{jobId})
        SB-->>Vue: 返回当前进度
        Vue-->>User: 显示进度条 + 处理张数
    end

    UNet->>UNet: 3D 后处理 (连通域分析、空洞填充)
    UNet->>FS: 写入 metadata.json
    UNet-->>SB: 任务完成通知
    SB-->>Vue: 批量分割完成
    Vue-->>User: 显示完成状态 + 统计信息

    %% 预览恢复
    User->>Vue: 查看病例分割结果
    Vue->>SB: POST /segment/caseResults (outputPath)
    SB->>UNet: POST /segment/caseResults
    UNet->>FS: 读取 images/ + masks/
    UNet-->>SB: 返回所有切片预览图
    SB-->>Vue: 切片预览列表
    Vue-->>User: 逐张查看分割结果
```

## 五、三个关键服务文件的关系

### 5.1 `D:\YDS\code\detect_service\mesh-api.py`
- **定位**：3D Mesh 重建微服务
- **依赖**：Flask, NumPy, SciPy, MONAI（可选）
- **功能**：从已分割的 3D 体积（.npy 切片堆叠）重建脑组织和肿瘤的表面网格
- **调用方**：Spring Boot 后端（在 3D 可视化场景中被调用）
- **端口**：5002

### 5.2 `D:\algorithms\V11-dmt\detect-api.py`
- **定位**：YOLO 脑肿瘤检测主服务
- **依赖**：Flask, Ultralytics YOLO, Pillow
- **功能**：对单张医学图像执行目标检测（边界框）或实例分割（多边形），输出肿瘤类型和置信度
- **调用方**：Spring Boot 后端（在 Detect 页面检测场景中被调用）
- **端口**：5001

### 5.3 `D:\algorithms\Pytorch-UNet-master\unet4engine.py`
- **定位**：UNet 脑肿瘤分割服务（TensorRT 加速）
- **依赖**：Flask, PyTorch, TensorRT, PyCUDA, NumPy, SciPy, OpenCV
- **功能**：对单张或批量医学图像执行像素级分割，输出掩码和多边形
- **调用方**：Spring Boot 后端（在 Mask/Multi 页面分割场景中被调用）
- **端口**：3408

### 关系总结

```
                         ┌───────────────────┐
                         │   Vue Frontend     │
                         │   (:9527)          │
                         └────────┬──────────┘
                                  │ HTTP
                                  ▼
                         ┌───────────────────┐
                         │ Spring Boot Backend│
                         │   (:9090)          │
                         └──┬──────┬──────┬──┘
                            │      │      │
                   HTTP     │      │      │     HTTP
              ┌─────────────┘      │      └─────────────┐
              ▼                    ▼                    ▼
    ┌──────────────────┐ ┌────────────────┐ ┌──────────────────┐
    │YOLO detect-api   │ │ UNet unet4     │ │ Mesh mesh-api    │
    │(:5001)           │ │ engine (:3408) │ │ (:5002)          │
    │目标检测/实例分割  │ │像素级语义分割   │ │3D表面网格重建     │
    │2D图像 → 检测框   │ │2D图像 → 掩码   │ │3D体积 → 顶点+面  │
    └──────────────────┘ └────────────────┘ └──────────────────┘
```

**三者的分工**：detect-api 负责"找"（在哪里、是什么），unet4engine 负责"切"（精确边界），mesh-api 负责"建"（3D 可视化）。它们各自独立部署，通过 Spring Boot 后端统一编排，前端无感知。
